# Perishable Knowledge — brand marks

Derived from the Harper Business jacket (2027). Use these rather than re-drawing.

## Color
| Token | Hex | Use |
|---|---|---|
| Signal red | `#F01820` | surfaces, buttons, the monogram tile, large type |
| Red ink | `#C4101A` | red text at small sizes (passes AA on ivory) |
| Jacket pink | `#F6D3D5` | the paper the spray fades into |
| Paper | `#FBF7EE` | light surfaces |
| Ink | `#1F1B17` | dark surfaces / text |

## Type
Display: **Anton** (Google Fonts) — the open-license stand-in for the jacket's condensed caps. Caps only, tight tracking.
If Harper's designer shares the real face and vector files, swap them in; proportions here are set to match.

## Files
- `pk-monogram.svg` — PK on red rounded tile (master). `-ink`, `-paper` variants; `-mark-only-*` are letters only, no tile.
- `pk-wordmark-{red,ink,white}.svg` — stacked PERISHABLE / KNOWLEDGE, justified block. PNGs at 2000px wide.
- `pk-lockup-1600.png` — square jacket-style lockup with subtitle, rule and spray fade (Instagram, slides, podcast art).
- `pk-social-1200x630.png` — Open Graph / Twitter card.
- `pk-avatar-1024.png` — rounded app-icon style avatar with fade (Substack logo, podcast badge, profile images).
- Site icons: `favicon.ico` (root), `favicon-32.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `site.webmanifest` (root).

## Rules of thumb
- Red is a surface, not a text color: white type on red, red type only at display sizes.
- The spray fade always runs red → paper; never the other way, never into white.
- Minimum clear space around the monogram: the width of the P stem.
